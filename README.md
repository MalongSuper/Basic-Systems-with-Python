# GUI Basic Systems with Python

This repository is a **collection of basic graphical user interface (GUI) systems built with Python**, focusing on desktop applications and interactive programs.

The projects use Python GUI frameworks such as **Tkinter, PyGame, and similar libraries**, with no HTML-based applications.

## Contents

The repository covers a variety of GUI-based systems, including:

* Basic GUI applications
* Interactive desktop systems
* Forms and input-based applications
* Simple utilities and tools
* Small simulations and interactive programs
* **Games and game-like applications** using PyGame
* Other GUI experiments and projects

The projects range from **simple demonstrations of GUI concepts to more complete interactive systems and games**.

## Notes

* Projects are built primarily with **Python-based GUI libraries**.
* **HTML, CSS, and JavaScript are not used** as the primary interface technologies in this repository.
* The repository focuses on practicing **GUI development, event handling, user interaction, and application structure** with Python.
* More systems and projects may be added over time.
